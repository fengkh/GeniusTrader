# 开发路线图

## 第六阶段补充：外部来源与公告候选试点

- 当前阶段：实现外部来源注册表、公告 Provider 接口、CNINFO 实验 Adapter、SSE 有限 Adapter、公告元数据标准化、去重、当前用户自选股匹配、用户私有候选收件箱、按需 PDF 提取和人工导入 InformationItem。
- 本阶段不做：后台调度、队列、全市场扫描、自动导入、自动 AI、自动通知、政府政策自动采集、国际机构自动同步、财经媒体自动采集、微信、行情或估值。
- 后续顺序：公告候选收件箱试点；国内政府与国际官方来源可行性 Spike；国内政府政策候选收件箱；国际官方信息候选收件箱；授权财经媒体商业和法律评估；获得授权后开发媒体 Provider；最后再评估自动调度。
- 自动调度、全市场公告监控和财经新闻自动化不得早于来源授权、留存、再展示、重试频率和用户通知策略确认。

本文描述从产品文档基线到第一版私人测试的阶段计划。本轮产品负责人已关闭 Mock 原型前必须确认的产品问题，后续可以进入 Mock 原型阶段；仍不得在未经确认前初始化工程、编写业务代码或接入真实数据。

目标：

- 建立 README、AGENTS、PRD、页面架构、流程、数据、AI、安全、领域模型和验收文档。
- 记录已确认决策和开放问题。
- 明确 MVP 边界和禁止事项。

完成标准：

- 开放问题有明确负责人和确认计划。
- 文档之间不存在明显定义冲突。
