## 处理规则

- 开放问题未确认前，不得在 PRD、数据模型或实现中写成确定方案。
- 如果某个问题影响 MVP 验收，应在进入工程开发前关闭或明确阶段性决策。
- 如果新问题来自技术实现限制，应新增编号，不覆盖历史问题。
- 已确认的页面导航、首页和个股详情优先级、行情快照刷新口径、CSV 模板、异动规则分类、管理员密码重置、测试规模、AI 日志默认范围、反方证据检查定位、数据同步任务展示边界、用户设置范围和复盘导出边界不再列为开放问题。
- 普通个人设置中的“是否显示已退市股票”只是用户界面的显示过滤偏好，不代表 OQ-03 已关闭；完整停牌、退市和名称变更处理口径仍需在真实数据开发前确认。
- Tushare Spike 仅用于验证候选 Provider 能力边界；在能力报告经产品负责人确认前，不得关闭 OQ-01 或 OQ-02。
- AKShare、efinance 和 BaoStock 免费源 Spike 仅用于验证候选 Provider 组合能力边界；在能力报告经产品负责人确认前，不得关闭 OQ-01 或 OQ-02，也不得替代商业化前的数据授权和法律评估。
- 全市场每日复盘、个股估值中心和用户通知中心融合 Mock 原型仅用于验证页面表达、状态降级和跳转关系；不得因此关闭 OQ-01、OQ-09、OQ-10、OQ-11、OQ-12、OQ-13 或 OQ-14。
- 第四阶段已实现真实站内通知和站内通知偏好，但不代表外部通知通道、通知长期保留期限、自动摘要调度或微信接入已经确认；不得因此关闭 OQ-13 或 OQ-14。
- 估值相关开放问题未关闭前，不得把具体估值模型、权重、行业可比口径、历史分位口径或财务 Provider 写成已确定实现。
- 外部通知通道开放问题未关闭前，不得把微信公众号、邮件、Web Push 或移动 Push 写成已经接入。
## 后端第二阶段后仍保持开放的问题

- 具体行情、公告、资讯和财务数据供应商仍未最终确定。
- 分时真实接入能力、公告/资讯正式接入方式、具体异动阈值、Token 预算和日志保留期限仍需真实数据开发前确认。
- 抖音、小红书、微信公众号等平台是否可通过官方授权接口获得更多内容仍待未来评估；当前 MVP 仅支持用户粘贴链接和补充文本。
- 是否引入更细的 AI Provider 任务模型、多 Provider 路由或备用模型自动切换，进入后续 AI Gateway 扩展阶段再定。

## 第四阶段后仍保持开放的问题

- 全市场真实复盘、估值后端、行情 Provider、财务 Provider、板块热度权重和阈值仍未最终确定。
- 通知保留期限、自动摘要调度、外部投递策略、微信/邮件/Web Push/移动 Push 接入仍未确定。
- 当前 `daily_digest` 只表示不产生单条即时站内通知，未来是否形成真正定时摘要仍待产品负责人确认。
