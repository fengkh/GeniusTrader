# 行情 Provider 授权确认清单草案

日期：2026-07-28

本清单用于 GeniusTrader 上线前向行情数据供应商或法律顾问确认授权边界。技术可达不等于商业授权成立；任何 Provider 未完成本清单前不得标记为 `PRODUCTION_PRIMARY` 或 `production_enabled=true`。

## 一、授权范围

- 是否允许商业产品使用。
- 是否允许向登录用户展示。
- 是否允许私人测试版展示。
- 是否允许移动端浏览器展示。
- 是否允许服务端缓存。
- 允许缓存的最长时间。
- 是否允许保存历史数据。
- 是否允许展示衍生涨跌、均线、量化指标和估值字段。
- 是否允许将数据用于 AI 摘要、解释或复盘材料。
- 是否允许导出或再分发。

## 二、覆盖与口径

- 是否覆盖 SH、SZ、BJ。
- 是否覆盖停牌、退市整理、退市和名称变更。
- 是否覆盖最近完整交易日。
- 是否覆盖分时、日 K、指数、板块、财务和估值所需字段。
- 价格、成交量、成交额、市值、换手率、复权、涨跌幅和交易日的单位口径。
- 数据更正机制和历史回填方式。

## 三、服务条件

- 调用频率限制。
- 用户数限制。
- SLA 或可用性说明。
- 故障通知方式。
- 终止授权后的数据处理要求。
- 来源标识或版权声明展示要求。
- 是否需要另行签署合同或补充协议。

## 四、内部冻结记录

冻结 Provider 前必须记录：

- `source_code`
- 授权文件或合同引用编号
- `authorization_status`
- `usage_scope`
- `production_enabled`
- 可展示字段清单
- 不可展示字段清单
- 缓存和留存期限
- 复审日期
