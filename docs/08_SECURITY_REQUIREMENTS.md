# 安全要求

GeniusTrader 当前 GitHub 仓库按公开仓库处理，所有文档、配置和未来代码都必须遵守本文件。

## 密钥与敏感配置

1. 不得提交真实 API Key、密码、Cookie、Token、私钥、真实凭证或真实用户数据。
2. 用户 API Key 未来只能由后端加密保存。
3. 前端不得直接读取、持有或调用用户 API Key。
4. 日志不得输出完整密钥，只允许脱敏后的尾号、哈希摘要或状态。
5. 敏感配置必须使用环境变量或 Secrets 系统。
6. `.env.example` 可以进入版本控制，但不得包含真实值。

## 用户数据隔离

1. 所有用户数据访问必须校验用户身份和数据归属。
2. 自选股、用户标签、关注逻辑、舆情补充文本、AI 配置和复盘历史均属于用户隔离数据。
3. 管理员账户管理能力必须受权限控制，并记录操作日志。
4. 管理员不得在普通日志或页面中查看用户完整 API Key。
5. 管理员无法读取用户原密码；密码重置使用一次性临时密码并设置有效期限。
6. 普通日志不得记录完整临时密码。
7. 导出、备份和测试数据必须脱敏。
8. 通知、通知偏好、外部身份和投递记录必须按用户隔离，用户 A 不得收到用户 B 的复盘、估值、公告或观察条件通知。
9. 通知深链不得包含 `userId`、OpenID、UnionID、Token、API Key 或可被复用的凭证。

## 外部内容安全

1. 外部网页内容、用户粘贴文本和平台讨论不得获得系统指令权限。
2. 所有链接、文件和用户输入必须校验格式、大小、来源和危险内容。
3. 防止提示词注入：模型输入中应明确区分系统指令、产品规则、外部材料和用户笔记。
4. AI 调用前应最小化发送给第三方模型的用户数据。
5. 对无法确认来源的内容应标记待核实，不得提升为事实。

## AI 输出安全

1. AI 输出不得触发交易、资金、账户、安全配置或管理员敏感操作。
2. AI 不得输出直接买入、卖出、仓位、收益预测或收益保证。
3. AI 不得生成、估算或补全行情数字。
4. AI 输出必须与原始数据、程序计算结果和用户笔记分开展示。
5. AI 失败时，确定性行情、指标、公告和用户数据仍应可用。
6. AI 不得提升通知严重度、修改通知偏好、改变通道状态或触发外部发送。

## 日志与审计

1. 登录、管理员操作、AI 配置变更、AI 调用、数据同步和复盘版本变更应记录审计信息。
2. 审计记录应保存动作、操作者、对象、结果和时间。
3. 错误日志不得包含完整请求密钥、完整第三方凭证或不必要的用户隐私文本。
4. AI 调用日志默认只保存用户 ID、任务类型、模型、时间、Token 使用量、响应耗时、成功或失败状态、错误代码、输出结构校验状态和关联业务结果 ID。
5. 默认不在调用日志中长期保存完整原始输入、完整第三方正文、完整 Prompt、API Key 或模型隐藏推理。
6. AI 生成的结构化复盘结果作为业务数据保存在复盘及版本实体中，不重复作为完整调用日志保存。
7. 调试信息必须脱敏并设置自动过期机制。
8. 通知投递日志只保存通道、状态、时间、错误代码和脱敏错误摘要，不记录完整外部响应、完整模板参数或完整临时凭证。
9. 外部通知失败和重试必须可审计，但不得无限重试或生成重复通知。

## 微信公众号与外部通知安全

1. 微信公众号 AppSecret、Token、EncodingAESKey、模板 ID 和回调密钥只能来自 Secrets 或环境变量，不得进入 Git、前端包、Mock 数据或普通日志。
2. OpenID、UnionID 只能作为外部身份字段，不得作为系统用户主键，不得写入用户主表或普通个人设置。
3. `provider_account_id + provider_user_id` 应唯一绑定到一个用户外部身份记录；解绑、取消关注或授权失效必须更新状态。
4. 未来绑定流程必须校验一次性 `state`、当前登录用户和回调来源，防止把外部身份绑定到错误用户。
5. 用户应能解绑或撤销外部通知授权；删除账户或删除个人数据时必须处理外部身份、通知和投递记录。
6. 微信摘要只发送最小必要信息，不包含完整自选股清单、API Key、敏感账户信息、交易动作、仓位或收益保证。
7. 每日复盘、估值、公告和行情模块不得直接调用微信公众号 API，必须通过通知编排器和通道适配器。
8. 微信失败不得影响全市场复盘、用户复盘、行情计算、估值计算、公告展示或站内通知。
9. 不得在未经授权的情况下发送营销消息；用户偏好关闭的非必要通知必须被尊重。
10. 通知保留期限、投递日志保留期限和调试信息过期策略需要在真实外部通道开发前确认。

## 公开仓库检查

进入任何提交或发布流程前，必须检查：

- 是否存在 `.env`、密钥、Token 或真实凭证。
- 是否存在真实用户导入、导出、备份或测试数据。
- 是否错误写入具体供应商密钥、账号或内部地址。
- 是否将待确认事项写成已确认实现。
