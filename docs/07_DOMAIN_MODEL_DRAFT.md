# 领域模型初稿

本文只定义实体、字段类别、关系和生命周期，不生成 SQL、迁移文件或 ORM 模型。

## 核心不变量

- 标准分类不能被用户覆盖。
- 系统建议可以被用户接受、拒绝或忽略。
- 用户标签、个人分组和关注逻辑独立保存。
- 原始公告、资讯和舆情来源不可被 AI 摘要覆盖。
- AI 复盘原始版本不可被用户编辑覆盖。
- 用户修改复盘必须形成新的修订版本。
- 行情和程序计算指标不能由 AI 生成或补全。
- 观察条件验证状态可以进入下一次复盘材料。
- AI 调用日志不长期保存完整原始输入、完整第三方正文、完整 Prompt、API Key 或模型隐藏推理。
- OpenID、UnionID 和外部通知绑定信息不得作为用户主键，也不得写入用户主表或普通个人设置。
- 通知严重度由程序规则决定，AI 不得提升严重度、修改通知偏好或改变通道状态。
- 外部通知通道失败不得阻断复盘、行情、估值、公告或站内通知。

## 关系说明

- 一个用户拥有一个主自选股池，自选股池由多个自选股条目组成。
- 一只股票可以被多个用户关注，但每个用户的标签、分组、关注逻辑和复盘彼此隔离。
- 股票基础信息、标准分类和行情数据属于共享基础数据；用户分类和复盘属于用户私有数据。
- 标准行业板块、标准概念板块、动态市场题材和用户标签必须分离保存；板块筛选不得依赖用户标签字段实现。
- 分时、日K和量化概览属于确定性行情或程序计算数据；AI 只能解释，不能生成、补全或覆盖。
- 公告和资讯可以作为共享外部材料，但用户补充内容、用户关联和用户笔记属于用户私有数据。
- AI 调用记录必须能追溯任务类型、模型和状态，但不得泄露完整 API Key。
- 数据同步任务是后台任务概念，用户侧只通过今日页、个股详情和设置页看到最后更新时间、同步状态、数据来源、部分失败提示和重新刷新入口。
- 用户设置只影响当前用户页面展示，不修改原始行情、公告、资讯、复盘、用户标签、分组、关注逻辑或其他用户数据。
- 全市场复盘、板块热度、热门股票和估值结果是共享基础数据或程序计算结果；用户对其形成的笔记、观察条件和复盘引用属于用户私有数据。
- 估值输入和估值结果必须保留报告期、公告日期、数据取得日期、公式版本和输入来源；不得把当前市值反向证明为合理价值。
- 业务事件由业务模块产生，通知编排器只消费结构化事件；每日复盘、估值、公告或行情模块不得直接调用微信公众号 API。
- 一个用户可以绑定多个外部通知通道；外部身份与通知偏好独立于普通个人设置。
- 一个业务事件可以产生一条站内通知和多条通道投递记录；同一公告来自多个 Provider 时，应通过去重键合并为一条用户通知。

## 生命周期重点

- 标准分类：数据源同步生成，用户不可修改原始记录。
- 板块筛选数据：标准行业和标准概念来自标准分类；动态市场题材来自系统建议或规则识别并允许用户确认；用户标签不参与标准板块口径。
- 分时走势：供应商能力未确认前不得承诺真实可用；Mock 原型可使用确定性本地数据展示。
- 日K线和量化概览：作为个股详情 MVP 材料，必须保留来源、数据时间和缺失状态。
- 用户设置：新用户默认使用系统默认值；用户保存后按本人独立生效；无效值不得保存；保存失败时继续使用上一次有效配置。
- 是否显示已退市股票：仅作为用户界面的显示过滤偏好，关闭显示不删除历史自选股、行情、资讯、复盘和用户笔记；重新开启后历史记录可以重新显示。具体停牌、退市和名称变更处理口径仍需在真实数据开发前确认。
- 系统建议：生成后进入待确认状态，用户可接受、拒绝或忽略。
- 舆情条目：录入后可经历待解析、解析成功、解析失败、待分析、分析完成、归档。
- 复盘：先形成 AI 原始版本或用户手写版本；每次人工修改都创建新版本。
- 观察条件：从复盘中产生，下一交易日展示并由用户验证，验证状态可回流到后续复盘。
- 异动事件：由程序计算产生，AI 可解释但不能决定事件是否存在。
- 全市场每日快照：收盘后按数据源能力产生；如果只是有限样本，必须记录样本范围并禁止展示为全市场结论。
- 板块热度快照：由板块成分和历史行情计算生成；权重、阈值和最终公式版本需在真实数据开发前确认。
- 财务数据快照：只能在报告已披露且公告日期不晚于目标日期时进入估值输入；未来数据必须拒绝。
- 估值结果：随输入数据和公式版本产生，不覆盖历史版本；数据不足或模型不适用时保留不可用结果和原因。
- 用户外部身份：未来绑定成功后保存外部 Provider 用户 ID；解绑、取消关注、授权失效或通道不可用时更新状态，不删除业务历史。
- 业务事件：按事件目录生成，幂等键包含事件类型、用户、对象、通道、模板版本和业务日期等字段，避免重复通知。
- 通知：通知失败或外部投递失败不得回滚业务事件；过期和归档只影响展示状态。
- 通知投递记录：外部通道失败保留脱敏错误和有限重试结果；禁止普通日志记录完整密钥、完整外部响应或完整临时凭证。
