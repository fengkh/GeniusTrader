# 领域模型初稿

本文只定义实体、字段类别、关系和生命周期，不生成 SQL、迁移文件或 ORM 模型。

## 核心不变量

- 标准分类不能被用户覆盖。
- 系统建议可以被用户接受、拒绝或忽略。
- 用户标签、个人分组和关注逻辑独立保存。
- 原始公告、资讯和舆情来源不可被 AI 摘要覆盖。
- AI 复盘原始版本不可被用户编辑覆盖。
- 用户修改复盘必须形成新的修订版本。
- 行情和程序计算指标不能由 AI 生成或补全。
- 观察条件验证状态可以进入下一次复盘材料。
- AI 调用日志不长期保存完整原始输入、完整第三方正文、完整 Prompt、API Key 或模型隐藏推理。

## 实体清单

| 实体 | 字段类别 | 主要关系 | 生命周期 |
| --- | --- | --- | --- |
| 用户 | 身份标识、账号状态、认证信息摘要、创建时间 | 拥有设置、自选股、AI 配置、复盘和私有数据 | 管理员创建或邀请；可停用；正式公开前需扩展验证机制 |
| 管理员账户操作 | 操作者、目标用户、动作、结果、时间、临时密码状态摘要 | 关联管理员和目标用户 | 创建、重置密码、停用、启用等操作后永久留痕；不得记录完整临时密码 |
| 用户设置 | 时区、日期展示偏好、数字展示偏好、默认首页视图、是否显示已退市股票、基础界面偏好、更新时间 | 属于用户 | 用户创建后使用系统默认值；用户可编辑并按用户独立保存；保存失败时保留上一次有效配置；AI 接口、模型任务、用户标签、异动规则和管理员权限不得塞入此实体 |
| 用户 AI 配置 | Provider 类型、Base URL、模型名称、密钥密文、状态、更新时间 | 属于用户；被 AI 调用记录引用 | 创建、测试、更新、停用；不得明文返回前端 |
| 自选股 | 用户、股票、加入时间、状态、导入来源 | 连接用户和股票基础信息 | 添加、CSV 导入、移除、恢复或归档；重复股票默认不重复创建 |
| 个人分组 | 用户、分组名称、排序、状态 | 包含用户自选股 | 用户创建和维护 |
| 用户标签 | 用户、标签名称、颜色或显示属性 | 可绑定自选股、舆情、复盘 | 用户创建和维护，独立于标准分类 |
| 用户关注逻辑 | 股票、用户、关注原因、核心逻辑、状态、更新时间 | 关联自选股和复盘 | 用户创建；后续版本化记录变化 |
| 股票基础信息 | 股票代码、名称、市场、上市状态、来源、更新时间 | 被自选股、行情、公告引用 | 由数据源同步；名称变更需保留历史 |
| 标准分类 | 股票、分类体系、行业、概念、来源、更新时间 | 关联股票基础信息 | 由数据源同步；不可被用户覆盖 |
| 系统分类建议 | 股票、建议类型、建议值、依据、来源任务、状态 | 关联股票、用户、AI 调用或规则 | 生成后等待用户接受、拒绝或忽略 |
| 用户自定义分类 | 用户、股票、分类类型、分类值 | 关联用户标签、分组和关注逻辑 | 用户创建、编辑和删除 |
| 行情快照 | 股票、最新价相关字段、成交量额、来源、更新时间、同步状态 | 关联股票和数据同步任务 | 页面打开或用户手动刷新后可更新；不承诺自动分钟刷新 |
| 日行情 | 股票、交易日、开高低收、涨跌幅、振幅、量额、换手、市值、来源 | 关联股票和指标 | 每交易日收盘后入库，历史不可随意覆盖 |
| 程序计算指标 | 股票、交易日、指标类型、指标值、触发依据、对比基准、计算时间、规则版本 | 依赖行情、指数和板块数据 | 行情更新后计算；输入变化时可重算并记录版本 |
| 公告 | 股票、标题、发布时间、来源、采集时间、原始链接、正文或摘要 | 关联股票、资讯关系、复盘引用 | 采集或录入后保留原始元数据 |
| 资讯 | 标题、来源、发布时间、采集时间、链接、内容摘要、来源等级 | 关联股票、板块、舆情和复盘 | 采集或用户录入；去重后保留来源 |
| 资讯与股票、板块关系 | 资讯、股票、板块、关联类型、关联依据、确认状态 | 连接资讯和对象 | 系统建议或用户确认后保存 |
| 舆情收件箱条目 | 用户、平台、链接、原始元数据、用户补充文本、解析状态、分析状态 | 关联股票、板块、AI 任务 | 用户录入；解析、补充、分析、归档 |
| 博主 | 平台、博主名称、博主 ID、主页链接 | 被用户关注博主引用 | 用户创建或后续数据源识别 |
| 用户关注博主 | 用户、博主、备注、关注方向、状态 | 连接用户和博主 | 用户添加、编辑、取消关注 |
| 博主内容条目 | 博主、链接、标题、发布时间、用户录入时间 | 可转入舆情收件箱 | 用户手动录入为主 |
| 异动规则 | 规则分类、规则类型、阈值、说明、版本、启用状态 | 被异动事件引用 | 系统预设；规则分类已确认，具体阈值在真实数据接入和历史样本验证后决定 |
| 异动事件 | 股票、交易日、异动类型、规则、触发依据、对比基准、实际数据、规则版本、数据时间、计算时间、来源 | 关联自选股、指标和复盘 | 规则计算产生；可随规则版本重算 |
| 个股每日复盘 | 用户、股票、交易日、状态、创建时间 | 拥有复盘修订版本 | 由 AI 生成或用户创建；按交易日保存 |
| 自选股整体复盘 | 用户、交易日、状态、创建时间 | 汇总多个自选股材料和版本 | 每交易日可生成和修订 |
| 复盘修订版本 | 复盘对象、作者类型、版本来源、内容、引用、时间 | 属于单股或整体复盘 | AI 原始版本创建后不可覆盖；用户编辑产生新版本 |
| 观察条件 | 用户、来源复盘、股票或整体范围、交易日、条件内容、创建时间 | 来源于复盘修订版本 | 复盘生成或人工编辑时创建；次日进入待验证状态 |
| 观察条件验证 | 观察条件、目标交易日、验证状态、验证时间、用户备注 | 关联观察条件和后续复盘材料 | 用户标记为已发生、未发生、部分发生、无法判断或不再适用；可进入下一次复盘材料 |
| AI 调用记录 | 用户 ID、任务类型、模型、时间、Token 使用量、响应耗时、成功或失败状态、错误代码、输出结构校验状态、关联业务结果 ID | 关联 AI 配置和产物 | 每次调用后记录；不得包含完整密钥、完整原始输入、完整第三方正文、完整 Prompt 或模型隐藏推理 |
| 数据同步任务 | 数据类别、来源类型、状态、开始结束时间、错误摘要、最后更新时间 | 产出行情、公告、资讯等数据 | 定时、页面打开或手动刷新触发；用户侧只展示状态摘要，不设置独立用户页面 |
| 用户操作日志 | 用户、动作、对象、结果、时间、客户端摘要 | 关联用户和业务对象 | 关键操作后记录 |
| 产品决策记录 | 决策编号、内容、原因、影响范围、状态、日期 | 对应文档决策日志 | 产品负责人确认后记录；变更需新增记录 |

## 关系说明

- 一个用户拥有一个主自选股池，自选股池由多个自选股条目组成。
- 一只股票可以被多个用户关注，但每个用户的标签、分组、关注逻辑和复盘彼此隔离。
- 股票基础信息、标准分类和行情数据属于共享基础数据；用户分类和复盘属于用户私有数据。
- 公告和资讯可以作为共享外部材料，但用户补充内容、用户关联和用户笔记属于用户私有数据。
- AI 调用记录必须能追溯任务类型、模型和状态，但不得泄露完整 API Key。
- 数据同步任务是后台任务概念，用户侧只通过今日页、个股详情和设置页看到最后更新时间、同步状态、数据来源、部分失败提示和重新刷新入口。
- 用户设置只影响当前用户页面展示，不修改原始行情、公告、资讯、复盘、用户标签、分组、关注逻辑或其他用户数据。

## 生命周期重点

- 标准分类：数据源同步生成，用户不可修改原始记录。
- 用户设置：新用户默认使用系统默认值；用户保存后按本人独立生效；无效值不得保存；保存失败时继续使用上一次有效配置。
- 是否显示已退市股票：仅作为用户界面的显示过滤偏好，关闭显示不删除历史自选股、行情、资讯、复盘和用户笔记；重新开启后历史记录可以重新显示。具体停牌、退市和名称变更处理口径仍需在真实数据开发前确认。
- 系统建议：生成后进入待确认状态，用户可接受、拒绝或忽略。
- 舆情条目：录入后可经历待解析、解析成功、解析失败、待分析、分析完成、归档。
- 复盘：先形成 AI 原始版本或用户手写版本；每次人工修改都创建新版本。
- 观察条件：从复盘中产生，下一交易日展示并由用户验证，验证状态可回流到后续复盘。
- 异动事件：由程序计算产生，AI 可解释但不能决定事件是否存在。
